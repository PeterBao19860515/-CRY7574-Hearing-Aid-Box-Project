The browser MCP handshake and summary report the version actually embedded in the open page; a newer server must not claim an older open page has upgraded. The release workflow increments the patch once per subsequent authorized release push, rebuilds both private and empty artifacts, validates the public output and excludes private seeds/user data. A local build alone does not increment the version. Never push without user authorization.
