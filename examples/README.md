# Overall Plan demonstration

Open **CRY7574 Overall Plan Demo.html** directly in Chrome or Edge. It opens Schedule → Overall Plan with 24 phases and 10 milestones across product, acoustics, mechanical design, software, validation, platform pilot and release workstreams.

All dates, owners, recorded completion, risks and approvals are fictional examples. The planning horizon is 28 September 2026 through 15 February 2027; illustrative progress is as of 24 October 2026. Notes explain example deliverables and gate criteria. Prerequisites in Notes are descriptive only: the application does not calculate dependencies or automatically move dates.

The demo uses the separate IndexedDB database `CRY7574-Overall-Plan-Demo-20261024`; it does not add entries to the main application workspace. It contains no measurements, original source files, media, requirements or actual task records. Edits persist in the demo database only. Do not restore a complete demo backup over an existing production workspace merely to view this example.

`overall-plan-demo-items.json` contains the illustrative plan-entry metadata for review. It is not a complete workspace backup or a measurement-import file.

The main application and public distribution remain unchanged. The example is included as a fictional, isolated demonstration in the V1.0.2 source release; it is not an online deployment.
