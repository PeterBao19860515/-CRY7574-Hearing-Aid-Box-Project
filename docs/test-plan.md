# CRY7574 Acceptance Test Plan

Owner: Jams, Test Manager. Product decisions: Andy. Implementation: Lucas.

## Scope and evidence rules

The current deliverable is a single self-contained English HTML application that opens directly from a file, without Python, a backend or network access. Validate measurement review, reports, original-file downloads, editable project progress and browser storage/backup. The supplied Alpair5G report is a reference example, not CRY7574 validation evidence. Initial project work is unconfirmed and must not be presented as measured delivery progress. A passing software test is not a passing acoustic product test.

The source fixture contains 33 charts, 97 series, 14,971 points, and 174 null Y values. Test fixtures use temporary storage; acceptance tests must not mutate the user's working data.

## Test execution

For the current clean standalone workspace, run `tests/workspace-browser-qa.mjs` with the bundled Node/Playwright runtime. It opens the actual delivered file in offline Chrome, uses a separate persistent test profile, compares all real AP pairs and bytes, verifies daily management/cursor/plot/tools, restarts the browser and tests complete/invalid/legacy restore. It never starts a server or uses the working user profile/database. Earlier `portable-*.mjs` helpers retain the preceding UI's evidence. Static frontend review is explicitly distinguished from browser verification.

The retained server-version suite runs with `python3 -m unittest discover -s tests -v` from the project directory. These integration tests launch a temporary HTTP server and compare all reference values; they are historical server evidence rather than proof of standalone file-mode operation.

AP coverage includes portable synthetic OOXML fixtures and two optional original workbooks in the user's Downloads directory. The real-file tests run when those originals are available and skip explicitly if redistributed to a computer without them. They compare all original numeric pairs using an independent reader, confirm byte hashes and unchanged modification times, and never copy the originals into the repository. Independent read-only openpyxl inspection provides a second source check without becoming a runtime dependency.

The optional `tests/table-browser-qa.mjs` helper runs actual Chrome against its own temporary server and synthetic fixtures. It checks direct upload entry, numeric precision, zero/null display, partial last pages, live-poll pagination, exact AP and legacy reference source cells, unknown cell mappings and the bounded DOM for a 150,000-point chart. It writes compact evidence to `docs/browser-point-table-qa.json` and does not use the working user database.

`tests/portable-organization-api-qa.mjs` independently verifies file-mode libraries/tags, v1 migration and old backup restore, atomic bulk edits, retry idempotency, cross-tab writes, source/report immutability, and save-time chart/library count limits. It uses only a temporary Chrome profile and synthetic source fixtures.

`tests/portable-organization-ui-qa.mjs` tests actual multi-file Preview/Save with malformed input, a transient failure before commit and a lost acknowledgment after commit. It verifies retry without duplicates, 123-record pagination, explicit cross-page selection, exact bulk scope, filter combinations and live-poll removal of selections that leave the active filter. It runs offline with a disposable profile.

`tests/portable-zoom-qa.mjs` verifies exact cursor/rectangle bounds against independent log-X/linear-Y mathematics, using actual browser pointer pixels. It tests axis isolation, drag cancellation, reset, manual/Auto Y, fixed-Y resize, measurement changes, zero/null/tiny-Vrms data and complete persisted-workspace/report invariance. It uses offline Chrome with a temporary profile and synthetic sources.

`tests/portable-deletion-qa.mjs` exercises exact deletion guards, preview atomicity, hidden/bulk/filter scope, actual cancellation and wrong-password UI, concurrent stale reviews, shared/report-only source retention, orphan pruning, frozen deleted-linked backup restoration, report-only raw downloads, zero-library restart and create/import recovery. Every deletion uses a disposable browser profile and synthetic sources; the user's workspace and browser profile are never opened.

The clean workspace rebuild uses `tests/workspace-browser-qa.mjs` for the new daily-record and cursor journeys. Earlier helpers tied to the previous DOM remain historical evidence; changed navigation must not weaken original-value, source-byte, frozen-snapshot or persistence assertions. Current completed evidence is in `docs/browser-workspace-qa.json`, including exact record/series caps, cross-page bulk scope, actual source-cell mappings and secondary-tools checks.

`tests/workspace-decimal-export-qa.mjs` independently verifies decimal 1/2/3 display in raw values, cursor and actual canvas ticks; formatted resting controls plus exact mathematical axis precision; setting validation/persistence and old/full backups; 55-record same-Library selection and bulk tags; exact original downloads; normalized JSON roundtrip through the import UI; CSV parsing and PNG creation. `tests/workspace-trace-style-qa.mjs` tests style identity, automatic commits and retry, invalid API/import/backup rejection, actual canvas appearance and marker isolation, source invariance, new frozen reports and byte-identical legacy HTML, JSON/PNG exports, stable legacy defaults, reload/browser restart and complete backup restore.
