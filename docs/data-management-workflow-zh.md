软件名称：CRY7574 Hearing Aid Box Measurement Manage Software。
核心任务是管理每天产生的测试数据。

## A 两个主要工作区
```flow LR
导入原始文件 -> Data数据列表: 预览后保存
Data数据列表 -> 标签与信息编辑: 标记、查询和维护
Data数据列表 -> Plot图表: 勾选需要显示的记录
Plot图表 -> Data数据列表: 返回继续管理
```
Data 默认显示可见记录，不要求先进入某个 Library。
Library 继续作为最大的分类，用于导入归档和筛选。
例如，可以创建扬声器单体、整机和隔离度测试库。
报告、项目进度和备份放在次要工具入口。

## B 每天如何导入、标记和修改
| 操作 | 用法 |
| --- | --- |
| 导入 | 批量选择 Excel、CSV 或 JSON，指定资料库。 |
| 预览与保存 | 检查曲线、单位和点数，再明确保存。 |
| 标记 | 导入时添加共同标签，也可多选已有记录后加标签。 |
| 标注 | 在备注中填写条件、样品信息或异常说明。 |
| 查询 | 组合标签、测试日期、测试项、资料库和关键词。 |
| 修改 | 编辑标题、测试日期、测试项、标签和标注。 |
| 隐藏 | 暂时移出正常列表，在隐藏视图中可以恢复。 |
| 删除 | 核对范围、确认并输入 CRYSOUND。 |

一份 Excel 可以产生多条测量记录。
每条记录都保留与原始文件的关联。
测试日期与导入时间分开保存。
未知测试日期保持未知，不用导入日期代替。
默认按最近导入排序，方便找到刚导入的数据。

当前修改功能针对记录信息。
原始测量点和原文件不会被这些编辑改写。

## C 如何选择图表并读取 Cursor
在 Data 中查看单条记录，或勾选多条后进入 Plot。
同单位的记录可以叠加比较。
不同单位的数据需要分别查看，软件不自动转换。
图例用于开关某条曲线的显示。

| 图表操作 | 结果 |
| --- | --- |
| 输入 X / Y 最小值和最大值 | 精确调整显示范围。 |
| 选择 X、Y 或双轴并滚动滚轮 | 以鼠标位置为中心缩放。 |
| 左键拖动框选 | 放大所选区域。 |
| 恢复全图 | 返回完整范围和自动纵轴。 |
| 鼠标移入绘图区 | 显示 Cursor 和实时坐标。 |

Mouse X/Y 是鼠标位置对应的坐标。
Sample X/Y 是每条曲线最近的原始采样点。
不同曲线采样频率不同，Sample X 也可能不同。
缺失点显示 Missing，不插值，也不当作零。
真正的零值仍显示为零。
缩放、Cursor 和曲线开关只影响显示。

交互参考了 [Audio Precision 的图表与 Cursor 说明](https://www.ap.com/fileadmin-ap/technical-library/APx500_Users_Manual_4.3.0.pdf?force=)。
这是面向数据管理的简化查看器，不包含 AP 的全部功能。

## D 原始证据和日常备份
原文件保留文件名、字节和 SHA-256，可下载原件。
已有报告保持创建时的快照。
删除库包含库内记录及隐藏记录，需要确认和密码。
仍被其他记录或报告使用的原始文件会保留。
无人引用的原始文件会随删除清理。

数据保存在当前浏览器，不会写回 HTML 文件。
使用 Export backup 备份，换电脑时用 Restore backup 恢复。
仅复制 HTML 不会迁移后来导入的数据。

当前离线版保留现有存储边界。
每批最多 100 个文件，单文件最多 20 MB。
工作区最多 5000 条记录、1000 个原文件。
新增保存后的完整备份不超过 180 MiB。
浏览器实际可用空间也会限制保存。
