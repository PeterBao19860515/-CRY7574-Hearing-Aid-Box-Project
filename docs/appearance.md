# Appearance

Use the **Appearance** selector in the application header to choose **Light** or **Dark**. The first visit uses Light.

The choice belongs to this browser on this device. It is separate from shared measurement data, interface language, decimal precision and saved trace styles. Reloading the application retains the choice when browser storage is available. If the browser blocks preference storage, the application can still switch for the current session and reports that it cannot remember the choice.

Dark mode covers workspace panels, forms, dialogs, tables, Schedule timelines and chart backgrounds, axes and grid lines. Measurement trace colors, widths and line patterns remain as configured by the user. Very dark custom trace colors may need manual adjustment for visibility on a dark chart.

Exported plot PNGs use the visible chart background. Frozen reports and original uploaded files retain their existing content. Workspace backups do not include or overwrite the device's appearance preference.

This change is built into the local standalone HTML. It does not publish a cloud release or change the product version.
