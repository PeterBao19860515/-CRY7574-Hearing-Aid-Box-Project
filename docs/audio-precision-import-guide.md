原始 Excel 是数据来源，每张测量表是一条可管理的测试记录。软件保留原文件，从 AP 表头识别曲线、通道和单位，再按测试日期与测试项组织记录。

## A 软件如何组织数据

```flow LR
原始AP工作簿 -> 原始文件档案: 完整文件和SHA256
原始文件档案 -> 测试记录: 工作表、通道和测量点
测试记录 -> 分类检索: 测试日期、测试项和备注
测试记录 -> 报告快照: 测量值、说明和来源
```

| 层级 | 保存内容 | 你可以做什么 |
|---|---|---|
| 原始文件档案 | 上传的完整 Excel、文件名和文件校验值 | 下载原文件 |
| 测试记录 | 每张测量表的曲线、单位和来源位置 | 编辑标题、测试日期、测试项和备注 |
| 分类与检索 | 日期分组、测试项分组和内容搜索 | 组合筛选，查找一次测试的各项结果 |
| 报告快照 | 生成时的测量数据与说明 | 预览、打印和下载报告 |

Project Progress 独立记录项目进度。上传文件数量不会自动变成项目完成度。

同一份 Excel 的多张曲线表关联到同一原文件。标题相同的曲线也显示源文件名，便于区分 01 与 02。

## B 如何上传 AP 原始 Excel

| 步骤 | 英文界面入口 | 操作 |
|---|---|---|
| 1 | Test Data → Upload Excel | 选择 AP 导出的原始 .xlsx 文件 |
| 2 | Title / Test date / Notes | 按需填写标题、实际测试日期和备注 |
| 3 | Preview measurements | 检查识别出的测量表、单位、通道和点数 |
| 4 | Save import | 保存原文件和解析后的测量记录 |
| 5 | Group by / Test item | 按日期或测试项分类查看 |
| 6 | Edit details / Original file | 编辑记录信息，或下载完整原始 Excel |

保留 AP 原生表头，无需手工改成 Frequency、Value 两列。
测试日期不确定时可以留空。软件不会把文件创建时间或上传时间当成测试日期。
修改文件或导入信息后，请重新预览，再保存。

## C 这两份样本会如何拆分

| 文件 | AP 测量名称 | 测量点数 | 原始单位 |
|---|---|---:|---|
| 5G-01 | RMS Level | 1734 | dBSPL1 |
| 5G-01 | RMS Level → Smooth | 500 | dBSPL1 |
| 5G-01 | THD Ratio | 1300 | % |
| 5G-02 | RMS Level | 1661 | dBSPL1 |
| 5G-02 | RMS Level → Smooth | 500 | Vrms |
| 5G-02 | THD Ratio | 1346 | % |
| 5G-02 | Distortion Product Ratio (H2:H5) | 1520 | % |

两份文件共包含 7 张测量表、8561 个测量点。另外各有一张 Summary 表。
点数来自工作表中的数值记录，不含前四行表头。

## D AP 导入必须保留的区别

| 来源信息 | 软件处理原则 |
|---|---|
| 第 1 行测量名称 | 保留完整名称，避免工作表名截断造成混淆 |
| 第 2 行 Ch1 | 保留通道信息 |
| 第 3 行 X / Y、第 4 行 Hz / 单位 | 识别坐标含义与每张表的单位 |
| 第 5 行开始的数值 | 保留全部测量点，不插值、不重新平滑 |
| RMS Level → Smooth | 标为 AP 已平滑结果，与原始 RMS 曲线分开保存 |
| 02 文件的平滑表 Vrms | 保留电压单位，不改成 dB SPL，不做数值换算 |
| Summary 中的 N/A | 保留在原文件中，预览说明未导入为曲线，不解释为通过 |
| 数据中的真实 0 | 保留为 0，不当成缺失值删除 |

软件会显示原始单位和工作表来源。原始曲线与 AP 平滑曲线是两条不同的测量记录。

## E 编辑与下载之间的关系

编辑 Title、Test date、Test item、Notes 会更新管理信息。
原始 Excel 的内容及测量点保持不变。

| 操作 | 得到什么 |
|---|---|
| Original series values | 查看频率、原始数值和来源单元格，可切换序列与翻页 |
| Original file | 上传的完整 Excel，字节内容一致 |
| Export CSV | 解析后测量点的表格导出 |
| Create report | 当前选中测量记录的报告快照 |
| Edit details | 可持续维护的记录标题和说明 |

已有报告保留生成时的内容。修改记录后重新生成报告，可得到更新后的快照。

## F 本次适配的范围

本次以你提供的两份 AP 工作簿作为兼容性样本。
它们采用单通道 X/Y 表头、Hz 频率轴和独立单位行。
预览会列出可识别的测量表和 Summary 的处理结果。
遇到无法识别的非空测量表，软件会提示具体问题，避免漏掉数据。

软件当前在本机运行，实际测量日期由用户填写。
工作簿保留在本机的数据档案中，原文件不会因导入而被改写。
